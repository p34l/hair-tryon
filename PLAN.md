# PoC: AR-примерка цвета волос в браузере

Документ-спецификация для пошаговой сборки прототипа. Цель прицела — этап 2
включительно: рабочий real-time PoC, который красит волосы с камеры без лагов,
не красит руки и бороду, имеет переключатель Intense/Pastel и стабильную
немерцающую картинку.

Выполнять строго по этапам, в конце каждого сверяться с критериями приёмки.
Не переходить к следующему этапу, пока текущий не даёт заявленный результат.

## 0. Контекст и принципы

Веб-приложение (включая мобильные браузеры), которое берёт видеопоток с
фронтальной камеры, в реальном времени сегментирует волосы, перекрашивает их в
выбранный цвет с сохранением текстуры/теней/бликов и выводит результат на экран.
Руки и борода не окрашиваются. Картинка стабильна между кадрами.

Не одна большая модель, а связка из трёх элементов:

1. **Сегментация волос** (MediaPipe Image Segmenter, модель SelfieMulticlass,
   даёт класс `hair` напрямую) — получаем маску волос.
2. **MediaPipe Face Landmarker** — точки лица для маски нижней челюсти и
   исключения бороды (этап 1).
3. **Рендеринг через GLSL fragment shader в WebGL2** — перекрашивание per-pixel
   с сохранением яркости.

Та же схема, что у Google в статье *"Real-time Hair Segmentation and Recoloring
on Mobile GPUs"* (arXiv 1907.06740). Повторяем на открытом стеке.

Семантический сегментатор классифицирует руку как НЕ-волосы → рука не попадает в
маску и не красится. Отдельной работы по окклюзии в PoC не требуется.

**Стек:** React + TypeScript, Vite, raw WebGL2 (без three.js), MediaPipe Tasks
Vision (`@mediapipe/tasks-vision`), Web Worker для инференса.

**Перформанс-принципы (закладывать с этапа 0):**
- Инференс на 256×256, апскейл маски билинейно при сэмплинге текстуры.
- Инференс в Web Worker (segmentForVideo синхронный, блокирует поток).
- `requestVideoFrameCallback` как драйвер цикла (фолбэк на rAF).
- Рендеринг (перекраска) на полном разрешении — дёшево, per-pixel.

## 2. Этап 0: базовый real-time recoloring  ✅ ГОТОВО

Волосы красятся в реальном времени с камеры, руки автоматически не красятся.
Без исключения бороды и стабилизации.

- [x] Vite + React + TS, живое видео с камеры на canvas (mirror).
- [x] Сегментация волос в Web Worker, маска приходит потоком (15+/c).
- [x] WebGL2 рендеринг: HSL-перекраска с сохранением L (текстура/тени видны).
- [x] UI выбора цвета (скролящийся ряд пресетов + карточка продукта).
- [x] Переключатель Intense/Pastel (один uniform strength + satScale).
- [x] Debug-режим: загрузка фото вместо камеры (для теста без вебки).
- [x] Кнопка фото: отсчёт + фриз кадра, с защитой от мультитапа.

**Критерий:** волосы перекрашиваются в реальном времени, рука НЕ красится,
текстура волос видна сквозь цвет. ✅ Подтверждено.

## 3. Этап 1: исключение бороды  ⏳ СЛЕДУЮЩИЙ

Борода и усы не окрашиваются, даже если сегментатор принял их за волосы.

- [ ] Подключить FaceLandmarker (478 точек) в `faceLandmarks.ts`.
- [ ] По landmarks контура лица и jawline построить полигон нижней части лица.
- [ ] Растеризовать в exclusion-маску.
- [ ] `maskProcessing`: финальная маска = hair × (1 − exclusion).
- [ ] Опционально добавить в exclusion класс face-skin (индекс 3).

**Критерий:** у бородатого человека волосы красятся, борода/усы — нет, граница
по линии челюсти чистая.

## 4. Этап 2: стабильность и качество краёв  ⏳

Картинка не мерцает, края мягкие.

- [x] EMA-сглаживание маски между кадрами (`mask_t = α·cur + (1−α)·prev`,
      α в `config.ts`). *Включено, требует визуального подбора α.*
- [x] Feathering краёв маски: 5×5 box-blur в фрагментном шейдере
      (`recolorShader.ts`, радиус `FEATHER_RADIUS` в `config.ts`). Guided filter —
      в roadmap.
- [x] FPS-счётчик (в углу). Проверка на разных лицах/освещении — за пользователем.

**Критерий:** при неподвижной голове край волос не «кипит», края мягкие,
без эффекта аппликации.

## 5. Производительность — заложено с этапа 0

256×256 инференс; маска апскейлится билинейно; инференс в Web Worker;
`requestVideoFrameCallback`; реалистичная цель 15–30 FPS на мобильном.
WebGPU не считать автоматически быстрее WASM — для PoC достаточно WASM-пути.

## 6. Что НЕ делаем в PoC (явные границы → roadmap клиенту)

- LUT-интерполяция light/dark по средней яркости (фотореалистичный dye,
  переход тёмные→светлые, серебро/чёрный). HSL с сохранением L достаточно для PoC.
- Hair matting тонких прядей через RVM/MODNet. Binary mask + feathering достаточно.
- Своя обученная модель сегментации. Берём готовый MediaPipe; переход — после
  замеров на целевых устройствах.
- Окраска отдельных прядей, градиенты, сохранение/шаринг.

## 8. Заметки по реализации (отклонения от исходного брифа и почему)

- **URL модели SelfieMulticlass** в брифе устарел (`/float/`). Актуальный путь —
  `/float32/`: `https://storage.googleapis.com/mediapipe-models/image_segmenter/
  selfie_multiclass_256x256/float32/latest/selfie_multiclass_256x256.tflite`.
- **MediaPipe в Web Worker:** в module-воркере падает с `ModuleFactory not set`
  (внутренний загрузчик использует `importScripts`, недоступный в module-воркерах
  — google-ai-edge/mediapipe#5257, #5527). Решение: **классический воркер** +
  `importScripts` локального CJS-бандла. Бандл и WASM лежат в `public/mediapipe/`
  (CDN отдаёт `.cjs` с MIME `application/node`, который `importScripts` отвергает).
  Код воркера обёрнут в IIFE, чтобы его переменные не конфликтовали с глобалами
  минифицированного бандла.

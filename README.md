# Hair Try-On PoC

AR-примерка цвета волос в браузере: live-видео с камеры → сегментация волос
(MediaPipe) → перекраска в WebGL2-шейдере с сохранением текстуры и теней.
Руки/лицо не красятся (семантическая маска). Есть переключатель Intense/Pastel
и debug-загрузка фото вместо камеры.

## Как запустить (не нужно знать стек)

```bash
npm install      # один раз — поставить зависимости
npm run dev      # запустить локальный сервер
```

Терминал покажет ссылку вида `http://localhost:5173/`. Открой её в браузере
(лучше Chrome), разреши доступ к камере — и увидишь себя с перекрашенными
волосами. Кликай по кружкам цветов внизу, переключай Intense/Pastel слева.
Остановить сервер — `Ctrl+C` в терминале.

- **Нет камеры или не хочешь её включать?** Нажми кнопку ⤓ слева и загрузи
  любое фото с лицом — перекраска работает и по фото.
- **Кнопка 📷** — отсчёт и «снимок» (фриз кадра). Тап по снимку закрывает его.

## Что под капотом

| Слой            | Технология                                              |
|-----------------|---------------------------------------------------------|
| Камера/кадры    | `getUserMedia` + `requestVideoFrameCallback`            |
| Сегментация     | MediaPipe Image Segmenter (SelfieMulticlass) в Web Worker |
| Перекраска      | WebGL2 fragment shader, HSL с сохранением яркости (L)    |
| UI              | React + TypeScript, Vite                                |

Структура и пошаговый план — в [PLAN.md](PLAN.md). Сейчас сделан **Этап 0**
(рабочий real-time recoloring); этапы 1 (исключение бороды) и 2 (стабильность +
мягкие края) — следующие.

## Сборка продакшн-версии

```bash
npm run build    # результат в dist/ — статика, заливается на любой хостинг
npm run preview  # локально посмотреть собранную версию
```
